# Catálogo 2.0 — Shopping de Flores

- Vitrine responsiva, cartões consistentes e imagens sem corte.
- Busca por palavras sem distinção de acentos, filtros por todas as categorias e ordenação.
- Exibição inicial de 24 produtos com carregamento progressivo dos demais já consultados.
- Galeria de até três fotos na página de produto.
- Navegação interna para categorias; atendimento pelo WhatsApp existente.
- Cupons continuam no checkout interno. Os arquivos de checkout, pagamento, cupons e Supabase foram preservados integralmente.

## Publicação e testes
Use as mesmas variáveis de ambiente do projeto anterior. Execute npm install e npm run build antes do deploy. Teste busca, filtros, fotos, checkout, cupom, Pix e cartão no ambiente de homologação. Não execute as migrações de referência automaticamente. Nenhum backend de produção foi alterado.
